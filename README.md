# 100 Days Code Challenge (October Edition)

This repository contains my progress for the **100 Days Code Challenge** during the month of October.

## About

The goal of this challenge is to improve consistency and coding skills by solving at least one problem every day for 100 days.  
All code in this repository is written in Python.

## Structure

- Each file represents the solution to a problem solved on a particular day.
- File names may correspond to the day or the problem tackled.

## How to Use

1. Browse the repository to view daily solutions.
2. Each Python file is self-contained and can be run independently.
3. To run a file:
   ```bash
   python filename.py
   ```

## Motivation

- Build and maintain a daily coding habit.
- Learn new concepts and reinforce existing knowledge.
- Track progress and reflect on coding journey.
